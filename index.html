What ZipFlow is

An archive tool that answers the question first.

ZipFlow is a free, local-first archive manager for Windows 10 and 11. It inspects ZIP, 7z, RAR (via 7-Zip), TAR and 25+ other archive formats before extraction, reports seven classes of security risk, and recommends compression settings based on the files inside. It runs entirely offline.

Inspect before extract

Seven checks run against the archive index. Path traversal and symlink escapes are blocked by default; everything else is reported with the exact entry names.

Recommend before compress

ZipFlow samples the file mix, then suggests a container, method and level with an estimated saving and runtime. No parameter guessing, no wasted CPU.

One engine, three shells

The GUI, the zf command line and the localhost HTTP API call the same core. Behaviour and errors stay consistent across all three.

Archive health report

Seven checks. One score. A report you can hand to CI.

A compressed file is a small filesystem with paths, links and sizes that the sender controls. ZipFlow reads that metadata before a single byte is written to disk.

The seven archive safety checks in ZipFlow
Check What ZipFlow looks for Action
Path traversalZip Slip · CWE-22 Entries whose resolved path escapes the destination: ../, absolute paths, drive letters, UNC paths. Blocked
Symlink escapelink plus write-through A symbolic link pointing outside the extraction root, followed by an entry that writes through it. Blocked
Compression bombresource exhaustion Extreme expansion ratios, oversized declared output or entry counts that could exhaust disk or memory. Flagged
Weak encryptionZipCrypto Legacy ZipCrypto instead of AES-256, outdated parameters, or encrypted entries that cannot be verified. Flagged

How the score works

The report starts at 100. Each finding subtracts points by severity: low 3, medium 12, high 30, critical 60. A score of 100 means no issues were found.

The risk label comes from the worst single finding, not the score. A file can score 70/100 and still be marked high risk because one integrity check failed, as in the screenshot above.

Every report exports to JSON with entry names, severities, check results and skipped checks, so the same data can gate a build or feed a ticket.

zf s archive.zip --json
{
  "format": "zip",
  "entry_count": 105,
  "risk_level": "high",
  "score": 70,
  "findings": [
    {
      "check": "integrity",
      "severity": "high",
      "title": "Integrity anomalies"
    }
  ],
  "checks_skipped": {}
}

Not an antivirus. ZipFlow inspects archive structure and extraction attack patterns. It does not scan file contents for malware signatures. Keep Windows Security or another antivirus enabled, and treat a clean report as one signal, not a guarantee.

Smart compression

The format question, answered with evidence.

Most tools ask you to choose a format, a method and a level, then hope for the best. ZipFlow samples the files first and classifies what is inside: source code, documents, images, video, already-compressed media, binaries.

The recommendation includes a container, a method, a level, an estimated saving and an estimated runtime. Every option is labelled with who can open it:

  • ★ Opens everywhere — Explorer, macOS, Office, phones, cloud drives
  • ◐ Needs a newer OS — for example Windows 11 24H2+ for TAR.ZST
  • ! Needs 7-Zip — smaller output, but the recipient must install a tool

Add --info to any create command to see the plan, the free disk space and the estimated result without writing a file.

GUI · CLI · API

One engine. Three ways in.

The engine layer has no Qt dependency. That is why the desktop app, the zf command and the HTTP API produce the same behaviour and the same errors.

  • GUI — drop an archive, open Health Report, export JSON
  • CLI — create, extract, list, test, recommend, scan, serve
  • API — FastAPI on 127.0.0.1 with a bearer token
  • JSON output — health reports and recommendations for automation
  • Stable exit codes — 0 ok, 1 error, 2 usage, 3 security block, 4 wrong password, 5 7-Zip missing

The core also enforces path safety even when you ignore the report: every write goes through a SecurityGuard layer.

zf — command line
# scan before extracting; JSON for CI
zf s suspicious.zip --json

# create the default: ZIP + Deflate L9
zf a dist.zip ./src

# smaller, but the recipient needs 7-Zip
zf a dist.7z ./src -f 7z

# plan only: no file is written
zf a big.zip ./data --info

# extract, recommend, test
zf x dist.zip -o ./out
zf r ./src --prefer auto
zf t dist.zip

# localhost API with a bearer token
zf serve --port 8765

Privacy

No network capability. Not a setting.

ZipFlow does not ask you to trust a privacy toggle. The Microsoft Store package omits the internetClient capability, so Windows itself prevents network access at the OS boundary.

  • No telemetry, analytics or crash uploads
  • No account, cloud sync or ads
  • No file names or paths leave the device
  • Settings live in %APPDATA%\ZipFlow\settings.json

FAQ

Questions people ask before installing.

Is ZipFlow free?

Yes. ZipFlow is free to download and use, with no account, ads, in-app purchases or usage limits. It is licensed under LGPL-3.0, and the licence text is included in the repository.

Does ZipFlow collect any data?

No. ZipFlow has no telemetry, no analytics and no cloud sync. The Microsoft Store package does not declare the internetClient capability, so Windows itself blocks network access. Your files, filenames and archive paths never leave the device.

Can ZipFlow open RAR files?

ZipFlow can list and extract RAR archives when 7-Zip is installed, because it uses the external 7-Zip engine to read the proprietary RAR format. RAR creation is not supported. Built-in formats such as ZIP, 7z and TAR work without 7-Zip.

Does ZipFlow replace an antivirus?

No. ZipFlow checks archive structure and known extraction attack patterns, not malware signatures. It does not scan file contents for viruses. Keep Windows Security or another antivirus enabled, and treat a clean health report as one signal, not a guarantee.

How does the archive health score work?

The score starts at 100. Each finding subtracts points by severity: low 3, medium 12, high 30, critical 60. A score of 100 means no issues were found. The risk label (low, medium, high or critical) comes from the most severe finding, and every report can be exported as JSON.

What formats can ZipFlow create?

ZipFlow writes seven containers: ZIP (the default), 7z, TAR, TAR.GZ, TAR.BZ2, TAR.XZ and TAR.ZST. ZIP supports Zip64, Deflate levels 1–9, AES-256 encryption and optional Zopfli compression. Each option is labelled with whether the recipient can open it without extra software.

Does ZipFlow work offline?

Yes. Every feature, including the local HTTP API, runs on your machine. The API binds to 127.0.0.1 and requires a bearer token. ZipFlow makes no outbound network requests.

Is there a command-line interface?

Yes. The packaged app exposes zf, and the source build uses python -m zipflow --cli. Commands cover create, extract, list, test, recommend, health scan and a localhost API. Exit code 3 means a critical path traversal or symlink escape was found, which can be used as a CI gate.

Which Windows versions are supported?

ZipFlow 1.0.0 supports 64-bit Windows 10 version 1809 or later, and Windows 11. It is distributed as an MSIX package through the Microsoft Store and as a portable build on GitHub.

Why does ZipFlow default to ZIP instead of 7z?

ZIP opens in Windows Explorer, macOS, Office, phones and cloud drives without installing anything. 7z usually produces smaller files, but the recipient needs 7-Zip or a compatible tool. ZipFlow defaults to the format that works everywhere and lets you choose 7z when size matters more.

Is ZipFlow open source?

Yes. ZipFlow is distributed under the LGPL-3.0 open-source licence. The licence text is in the repository, and third-party notices are included with the app.

Can I use ZipFlow in CI or a script?

Yes. zf s archive.zip --json prints a machine-readable report. The command returns exit code 3 when a critical path traversal or symlink escape is found, so it can fail a build. Other findings can be enforced with your own threshold by parsing the JSON.

Privacy Policy

ZipFlow collects no data. The application makes no network requests and runs entirely offline.

Last updated 7 October 2026 Applies to version 1.0.0 and later

The short version: ZipFlow does not collect, upload or share any personal information. There is no telemetry, no analytics, no account and no cloud sync. The Microsoft Store package does not declare the internetClient capability, so Windows itself blocks network access.

1. What we collect

Nothing. In particular, ZipFlow does not collect:

  • Identity information (name, email address, phone number, account)
  • Usage data, behavioural analytics or click tracking
  • Crash reports or diagnostic logs
  • Device identifiers, hardware fingerprints or advertising IDs
  • File contents, file names or file paths

No registration or sign-in is required.

2. Network requests

The application runs entirely offline. There is no code path that performs an outbound network request.

The MSIX package does not declare the internetClient capability in its application manifest. Network access is therefore blocked by the operating system, not by a setting inside the app.

The optional local HTTP API binds to 127.0.0.1 and requires a bearer token. It accepts connections from the same machine only; it is not reachable from a network.

3. Crash diagnostics

If the application crashes, Windows Error Reporting may generate a local crash dump. Those files are produced by Windows and are not transmitted to ZipFlow or any third party automatically. You decide whether to view or upload them.

4. Local storage

ZipFlow writes one settings file in your user profile:

PathContents
%APPDATA%\ZipFlow\settings.json Interface language, theme, security thresholds, overwrite policy, recently opened archive paths, local API port and token

Temporary files, exported health reports and extraction targets are created only when you explicitly trigger the corresponding action. Uninstalling the app does not automatically remove the settings directory; delete it manually if you prefer.

5. Third-party components

ZipFlow may optionally invoke a 7-Zip executable already installed on your system to read formats such as RAR, ISO and CAB. 7-Zip is separate software governed by its own terms. ZipFlow passes it nothing beyond the local path of the archive you asked it to open.

Third-party notices are included with the app. ZipFlow's own licence text is in the repository's licence file.

6. Children's privacy

No data is collected, so no children's privacy issues arise. The app has no user-generated content, no social features and no advertising.

7. Changes to this policy

Material changes will ship with a new version and be noted in the app's About dialog with the version number. The current version of this page is always the authoritative text.

8. Contact

Questions about this policy can be filed at github.com/lijiannan1241/ZipFlow/issues. This page is the privacy policy URL used for the Microsoft Store submission.

隐私政策（简体中文）

最后更新：2026 年 10 月 7 日 · 适用于 1.0.0 及之后版本

简短版本：ZipFlow 不收集、不上传、不共享任何个人信息。没有遥测、没有统计分析、没有账号、没有云同步。微软商店安装包不声明 internetClient 能力，网络访问由 Windows 在系统层面阻断。

1. 我们收集什么

不收集任何数据。具体来说，不收集身份信息（姓名、邮箱、手机号、账号）、使用数据或点击统计、崩溃报告或日志、设备标识符或广告 ID，也不收集文件内容、文件名或文件路径。应用不需要注册或登录。

2. 网络请求

应用完全离线运行，代码中不存在对外部服务器的请求。安装包未申请 internetClient 能力，因此无法进行网络访问。可选的本地 HTTP API 只绑定 127.0.0.1，并要求 Bearer Token，不接受来自网络的连接。

3. 崩溃诊断

如果应用崩溃，Windows 错误报告机制可能生成本地崩溃转储文件。这些文件由 Windows 生成，不会自动发送给 ZipFlow 或任何第三方，是否查看或上传由你决定。

4. 本地存储

应用只在用户配置目录写入一个设置文件：%APPDATA%\ZipFlow\settings.json，内容包括界面语言、主题、安全阈值、覆盖策略、最近打开的压缩包路径、本地 API 端口与 Token。临时文件、导出的体检报告和解压目标只在你主动操作时产生。卸载应用不会自动删除该配置目录，如需清除请手动删除。

5. 第三方组件

应用可以选择调用系统上已安装的 7-Zip（7z.exe）来读取 RAR、ISO、CAB 等格式。7-Zip 是独立软件，其行为不受本政策约束。ZipFlow 不会向它传递除“待读取的本地文件路径”之外的任何信息。第三方组件清单与许可证随应用提供，也可在仓库的许可证文件中查看。

6. 儿童隐私

不收集任何数据，因此不存在儿童隐私问题。应用没有用户生成内容、社交功能或广告。

7. 政策变更

实质性变更将随新版本发布，并在应用的“关于”对话框中标注版本号。本页面的当前版本始终是权威文本。

8. 联系方式

如对本政策有疑问，请到 github.com/lijiannan1241/ZipFlow/issues 提交。本页面同时作为微软商店提交所需的隐私政策链接。
